# LICENCIA Y ATRIBUCIÓN

## EMPREespacio

**EMPREespacio**, anteriormente denominado **AppEmprendedores**, es un proyecto desarrollado como una adaptación y transformación del proyecto original **Mercari Clone**.

El proyecto original fue publicado en:

https://github.com/itsnotvii/mercari-clone

Cuenta de GitHub original:

**itsnotvii**

Autor asociado al proyecto original:

**Thomas Johnson**

Durante el desarrollo de EMPREespacio, el código base original fue modificado y adaptado para crear una aplicación orientada a emprendimientos locales de Rafaela, Argentina.

Entre las modificaciones y desarrollos realizados se encuentran, entre otros:

* Rediseño de la interfaz y experiencia de usuario.
* Adaptación del modelo de marketplace a una plataforma de emprendimientos locales.
* Eliminación o modificación de funcionalidades relacionadas con pagos internos.
* Modificación del sistema de publicaciones.
* Implementación de perfiles de emprendimientos.
* Implementación de favoritos de emprendimientos.
* Implementación de la vidriera de emprendimientos.
* Implementación de búsqueda y filtros.
* Implementación de reportes.
* Implementación de administración y roles.
* Implementación de banners administrables.
* Adaptación de la estructura de la base de datos.
* Adaptación de políticas de seguridad.
* Desarrollo de nuevas funcionalidades y componentes específicos para EMPREespacio.
* Desarrollo de la identidad, nombre y branding de EMPREespacio.

## Proyecto original

Parte de EMPREespacio se basa en código originalmente publicado como:

**Mercari Clone**

Repositorio original:

https://github.com/itsnotvii/mercari-clone

Cuenta publicadora original:

**itsnotvii**

El repositorio original indicaba una licencia **MIT** en su documentación.

Sin embargo, durante la revisión del repositorio original no se encontró un archivo `LICENSE` independiente en la raíz del repositorio que permitiera verificar directamente el texto completo de dicha licencia.

Por este motivo, esta atribución se mantiene de forma explícita como reconocimiento al proyecto original y como parte de la transparencia sobre el origen de parte del código utilizado.

## Alcance de la licencia MIT

La referencia a la licencia MIT corresponde al código del proyecto original que se encuentre cubierto por la declaración de licencia realizada por sus autores.

Esta atribución **no significa que la totalidad de EMPREespacio se encuentre publicada bajo la licencia MIT**.

El código original proveniente de Mercari Clone mantiene los derechos y condiciones correspondientes a su proyecto original.

Las modificaciones, adaptaciones, funcionalidades, diseños, contenidos y demás materiales desarrollados específicamente para EMPREespacio no quedan automáticamente licenciados bajo MIT por esta atribución.

## Código y materiales desarrollados para EMPREespacio

EMPREespacio contiene una combinación de:

* Código original proveniente del proyecto Mercari Clone.
* Código modificado o adaptado a partir del proyecto original.
* Código desarrollado específicamente para EMPREespacio.
* Diseños e interfaces desarrollados para EMPREespacio.
* Identidad y branding de EMPREespacio.
* Nombre y elementos gráficos propios.
* Estructuras y configuraciones específicas de la aplicación.
* Contenido propio.

La presente atribución no pretende reclamar la autoría del código original perteneciente al proyecto Mercari Clone.

## Transparencia

EMPREespacio no fue desarrollado completamente desde cero.

Parte de su base inicial proviene del proyecto **Mercari Clone**, que posteriormente fue modificado, rediseñado y adaptado para desarrollar una aplicación con objetivos, funcionalidades, identidad y modelo de uso diferentes.

La atribución al proyecto original se mantiene como reconocimiento al trabajo previo utilizado como punto de partida.

El cambio de nombre de **AppEmprendedores** a **EMPREespacio** corresponde únicamente al proceso de evolución y branding del proyecto y no modifica la atribución correspondiente al código original utilizado como base.
